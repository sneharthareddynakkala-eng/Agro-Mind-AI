# Nexus Agentic System Builder

Enter your own OpenRouter API key in the app. The key is used only for the current
browser session and is not included in this repository.

For this public demo, generated Python code is displayed but never executed.
Uploaded agent systems and chat history are kept in the current browser session
and are not written to shared storage. CSV uploads are limited to 5 MB.
